
# EcoSort AI

## Overview

EcoSort AI is a low-cost AI-assisted framework for plastic waste sorting and management decision support.

## Research Question

Can a computer vision system classify locally collected plastic waste and recommend appropriate management pathways?

## Objectives

- Build a real-world plastic waste dataset
- Train an image classification model
- Develop a decision framework for recycling, pyrolysis suitability, rejection, or manual review

## Dataset

Current dataset:
290 locally collected plastic waste samples

Data fields:
- Plastic type
- Weight
- Source
- Condition
- Resin code
- Images

## Methodology

1. Data collection
2. Plastic classification
3. AI model training
4. Decision framework development
