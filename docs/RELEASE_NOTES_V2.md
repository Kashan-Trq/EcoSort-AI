# Release notes — EcoSort AI v2.0

**Delivered and unit-tested:** 450-record dashboard; sample-held-out data catalog; offline-capable PWA shell; mobile camera permission and capture workflow; image-upload fallback; on-demand OCR candidate extraction (requires CDN); optional pretrained MobileNet general object cues (requires CDN); human-resin-evidence confirmation; conditional literature-based pyrolysis example calculator; safe blocks on unsupported materials; Vercel static files; test suite.

**Not delivered or claimed:** privately hosted/verified Google Drive photographs inside ZIP; custom-trained and independently validated polymer classifier; lab-calibrated visual polymer recognition; real pyrolysis fuel yield observations; safe-to-operate pyrolysis machine; production domain/deployment URL; verified live browser/camera/OCR integration (environment blocks Chromium navigation).

**Test status:** Node test suite passed. Browser external-source and camera availability requires HTTPS deployment and human device check. No claims of performance accuracy are made.

**Suggested mobile demonstration:** use a bottle with an actual stamped #1 PET mark (app should correctly decline pyrolysis-oil estimate and prefer local recycling check); then demonstrate a clean PP item with a verified #5 mark, optionally supply measured mass, and explain that displayed fractions are experimental literature scenarios rather than proven yield for that item. Finally use a PVC #3 item and show the safety block. Never make a claim that object recognition alone confirms any polymer.
